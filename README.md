# 산스크리트 소사전

데바나가리·IAST 로마자로 찾는 산스크리트어 사전입니다.

- 한국어 풀이 핵심 어휘 665개 (불교·요가·영성·아유르베다·신화 등)
- 사전 표제어 21만여 개: Apte(1890), Monier-Williams(1899), Edgerton 불교 혼성 산스크리트(1953)
- 발음(국제음성기호·음절 장단), 데바나가리 쓰는 순서

영어 풀이는 크롬의 **한국어로 번역**(주소창 번역 아이콘 또는 마우스 오른쪽 버튼)으로 한국어로 볼 수 있습니다. 산스크리트 표제어와 한국어 화면은 번역되지 않도록 막아 두었습니다. 카카오톡 안에서 열면 번역 기능이 없으니 크롬이나 사파리로 여세요.

## 출처와 라이선스

사전 데이터(`dict/`)는 [Cologne Digital Sanskrit Dictionaries](https://www.sanskrit-lexicon.uni-koeln.de/)의 디지털판을 변환한 것으로, **CC BY-SA 4.0**을 따릅니다.

- V. S. Apte, *The Practical Sanskrit-English Dictionary* (1890)
- M. Monier-Williams, *A Sanskrit-English Dictionary* (1899)
- F. Edgerton, *Buddhist Hybrid Sanskrit Dictionary* (1953)

인용 출처 약어는 생략했습니다. 사전 표제어의 데바나가리·한글 음역은 자동 변환했고, Apte 합성어의 붙여 쓴 형태는 연성 규칙으로 자동으로 만든 것입니다. 핵심 어휘의 한국어 풀이와 `dict/ko.json`의 AI 번역은 검수되지 않았습니다.
